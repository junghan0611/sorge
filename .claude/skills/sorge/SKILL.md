# sorge — 돌봄의 순회

리포 절대경로: `~/repos/gh/sorge`. 어느 cwd에서 불려도 여기가 자리다.

## API

| 의도 | 명령 | 다음 수 |
|---|---|---|
| 전체 판 세우기 | `python3 ~/repos/gh/sorge/.claude/skills/sorge/scripts/sweep.py` | 다섯 갈래(판정 필요·빚·미표시·판정됨·조용함)를 읽고 무엇을 GLG에게 올릴지 고른다 |
| 형제에게 건넬 블록 | `… /sweep.py --brief` | 리포별 블록을 **그대로** `entwurf_v2`로 던진다. 요약하지 않는다 |
| 한 리포만 | `… /sweep.py --repo <name> --brief` | |
| 빚 기준 조정 | `… /sweep.py --debt 30` | 기본 15커밋 |
| 최근성 조정 | `… /sweep.py --recent-days 90` | 기본 35일. `판정 필요`에 오를 자격 |
| 기술스택 선례 | `grep -rl "native-image\|graalvm" ~/repos/gh/*/{run.sh,*.nix,*.edn} 2>/dev/null` | 선례 리포를 이름으로 건네고, 그 담당자가 읽게 한다 |

판정을 적는 곳은 `~/repos/gh/sorge/LEDGER.md` 하나다. **sweep은 아무것도 쓰지 않는다.**

## 계약 — 이걸 어기면 sorge가 아니다

1. **앞서 뛰어가고, 대신 뛰어들지 않는다.** 발견하고 이름 붙여 넘긴다. 남의 리포에
   커밋하지 않는다. 노트도 대신 쓰지 않는다 — 쓰는 손은 그 집 담당자와 `botlog` 스킬이다.
2. **"없다"는 결함이 아니다.** 담당자 문서 없는 리포, 수선 스킬 없는 리포는 정상이다.
   아직 판정되지 않았을 뿐이다. 묻지 않은 곳에 설치하지 않는다.
3. **파생 가능한 것은 저장하지 않는다.** 노트 유무·커밋 수·스킬 유무는 매번 다시 유도한다.
   `LEDGER.md`에는 사람의 판정만 — `불필요` / `보류` / `배정`. 파생 사실을 적는 순간
   그것은 마커가 되고, 마커는 관리 대상이 된다.
4. **자동 발신 금지.** 순회는 보고까지다. 형제를 부르는 것은 GLG의 손이다.
5. **출력은 표가 아니라 브리핑.** 표를 뱉으면 GLG가 여전히 리포를 돌아다녀야 한다.
   `--brief`가 그대로 던져지는 형태인 이유다. 블록은 노트 제목·보낸 이·돌아올 길을 달고 나간다 —
   받는 담당자가 되물어야 하면 순회가 자기 일을 넘긴 것이다.
6. **"없다"가 참일 때만 4번이 선다.** 있는 것을 없다고 읽는 오답은 원칙 자체를 무너뜨리므로
   다른 종류의 잘못이다. 2026-09-04 하루에 셋이 나왔다 — 내보내진 md를 읽어 갓 개명된 노트를
   없다고 함, `§` 언급을 담당자 문서로 쳐서 진짜를 가림, `hugo_lastmod`만 봐서 히스토리로 갱신된
   노트를 빚으로 셈함(entwurf 429 → 183). 판정 전에 **읽는 자리가 SSOT인지** 먼저 묻는다.

## 판단 기준

- **빚**: 노트가 마지막으로 손닿은 뒤의 커밋 수. **날짜가 아니다** — 커밋 0인 리포의 오래된
  노트는 낡은 게 아니라 정확한 것이다(실측: `denotecli` 109일 / 0커밋).
  기준선은 `#+hugo_lastmod`와 **`* 히스토리` 최신 줄 중 나중 것**이다. `agent-denote-add-history`는
  lastmod를 올리지 않으므로 lastmod만 보면 절차대로 갱신한 노트가 영영 빚으로 남는다.
  그래서 갱신 절차에 단계를 더하지 않고 읽는 쪽을 고쳤다.
- **판정 필요**: 노트 없음 + 대장에 없음 + `--recent-days`(기본 35) 안에 커밋. 셋 다여야 오른다.
  이 창을 넓히면 조용한 리포까지 판정 대상이 된다 — 넓힐지는 GLG가 정한다.
- **건강 신호**: 두 번째 순회부터 `판정 필요`가 0에 수렴하면 대장이 쓰이고 있는 것이다.
  안 줄면 스킬이 아니라 대장을 본다.

## 담당자 문서 갱신을 부탁할 때

`--brief` 블록에 이 세 줄이 이미 들어 있다. 형제에게 넘길 때 빼지 않는다:

- `denotecli read <id> --outline` 으로 뼈대 먼저 — 통째로 읽고 다시 쓰지 않는다
- 히스토리 한 줄 + 필요한 헤딩만 덧댄다 (Documents Grow, Not Get Edited)
- 쓰는 손은 `botlog` 스킬. `agent-denote-add-history` / `add-heading`
